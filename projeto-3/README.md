# 🐾 Pet Shop — Limpeza e Análise de Dados

## 📌 Sobre o Projeto

Este projeto foi desenvolvido em grupo com o objetivo de realizar a limpeza, organização e análise exploratória de dados de um Pet Shop, utilizando Python no Google Colab.

O trabalho procura transformar dados brutos em informações úteis, facilitando a identificação de padrões, tendências e possíveis oportunidades de melhoria para o negócio.

## 🎯 Objetivos

* Limpar e organizar os dados do Pet Shop.
* Identificar e tratar valores ausentes e dados duplicados.
* Verificar e corrigir inconsistências nos dados.
* Realizar uma análise exploratória dos dados.
* Criar visualizações para facilitar a interpretação dos resultados.
* Extrair informações relevantes para apoiar a tomada de decisões.

## 🛠️ Tecnologias e Ferramentas

* **Python** — linguagem utilizada no tratamento e análise dos dados.
* **Google Colab** — ambiente de desenvolvimento dos notebooks.
* **Pandas** — manipulação, limpeza e organização dos dados.
* **NumPy** — operações numéricas e apoio ao tratamento dos dados.
* **Scikit Learn** — Modelo e previsões.

## 🔎 Etapas do Projeto

1. **Carregamento dos dados:** importação do conjunto de dados para o Google Colab.
2. **Exploração inicial:** análise da estrutura, dos tipos de dados e das principais características do conjunto de dados.
3. **Limpeza dos dados:** identificação e tratamento de valores ausentes, duplicados e inconsistências.
4. **Transformação dos dados:** organização e preparação das informações para análise.
5. **Análise exploratória:** investigação de padrões, tendências e relações entre variáveis.
6. **Conclusões:** apresentação dos principais resultados e possíveis recomendações.

## 📊 Resultados Esperados

* Conjunto de dados mais limpo, consistente e organizado.
* Melhor compreensão das informações disponíveis sobre o Pet Shop.
* Identificação de padrões relevantes nos dados.
* Visualizações que facilitem a comunicação dos resultados.
* Desenvolvimento de competências práticas em Python e análise de dados.

## 💻 Como Executar o Projeto

1. Acede ao notebook do projeto no repositório GitHub.
2. Abre o ficheiro `.ipynb` ou importa-o para o Google Colab.
3. Se necessário, carrega o ficheiro de dados utilizado na análise.
4. Executa as células do notebook pela ordem apresentada.
5. Consulta os gráficos, resultados e conclusões.
