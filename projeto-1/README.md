# 🌱 Sistema de Rastreabilidade Agrícola

Projeto desenvolvido no âmbito do curso Técnico Especialista em Gestão da Informação e Ciência dos Dados.

## 📋 Descrição

Este projeto consiste na modelação e implementação de uma base de dados para rastrear o percurso de produtos agrícolas desde a produção até ao consumidor final.

O sistema permite acompanhar todas as etapas do processo produtivo, garantindo a rastreabilidade e a segurança alimentar.

---

## 🎯 Objetivos

- Registar informações da produção agrícola.
- Controlar colheitas e lotes.
- Acompanhar processos de embalagem e rotulagem.
- Monitorizar distribuição e comercialização.
- Garantir a rastreabilidade completa dos produtos.

---

## 🏗️ Modelo de Dados

O projeto foi desenvolvido seguindo as etapas:

1. Levantamento de requisitos.
2. Modelo Conceptual (DER).
3. Modelo Lógico.
4. Modelo Relacional.
5. Implementação SQL.

### Principais Entidades

- Produto
- Produção
- Colheita
- Embalagem
- Distribuição
- Cliente
- Funcionário

---

## 🔗 Relacionamentos

Exemplos de relacionamentos implementados:

- Produto é produzido em Produção
- Produção gera Colheita
- Colheita origina Embalagem
- Embalagem é distribuída
- Cliente recebe Produto
